# Changelog

All notable changes to the ERA5 CrocoDash extension are documented here.

## 1.0.0 — 2026-10-01

Author: Faezeh Maghsoodifar

- Added complete ERA5 atmospheric preprocessing for NCAR RDA `d633000`.
- Added eight CDEPS-ready atmospheric fields.
- Derived 2 m specific humidity from dew-point temperature and pressure.
- Added full-ERA5 and wind/pressure-only CrocoDash modes.
- Added stream overrides for CDEPS JRA-interface cases.
- Added ERA5 SCRIP and ESMF mesh creation.
- Added offline preprocessing tests and configurator tests.
- Added an NCAR Derecho/Casper setup runbook.
- Added a reusable Hurricane Ike template and executed 21-day example.
- Added verification for eight ERA5 streams and zero JRA data paths.
